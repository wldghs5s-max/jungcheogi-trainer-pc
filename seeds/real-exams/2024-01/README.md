# 기출 사진 전사·학습 검수 자료

목표는 개인 학습과 자격증 합격이다. 기출 고증보다 문항·정답·해설의 학습 정확도를 우선한다.

- `2024-01.transcribed.md`: 18문항 원문, 정답, 해설.
- `2024-01.transcribed.json`: 코드·표·보기·정답·해설을 분리한 구조화 자료.
- 사진 원본은 프로젝트 `public/`에 있다.
- JSON은 앱 Import API에 바로 넣는 파일이 아니다. 공단 공식 답안이 아니며, 학습용 검수본이다.
- 코드 문항은 컴파일러/인터프리터로 실행해 확인했다.
- 현재 DB와 풀이 기록은 변경하지 않았다.

## 원문에서 고친 점

- 1번: 지문 JAVA → C. `main` 반환형 `int` 명시.
- 9번: 보기 중복 ‘자연 조인’ 제거.
- 10번: 문자열 `ABCDEFGH` 확정.
- 13번: 대문자 분기 `% 25` → `% 26`.
- 11번: 원 숫자는 ⑤ main, ⑥ `new Child(10)`, ⑦ println. 정답은 `⑤ → ⑥ → ③ → ① → ⑦ → ②`.
