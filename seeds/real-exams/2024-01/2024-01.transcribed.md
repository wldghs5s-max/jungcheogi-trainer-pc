```java
class Connection {
    private static Connection _inst = null;
    private int count = 0;
    public static Connection get() {
        if (_inst == null) {
            _inst = new Connection();
            return _inst;
        }
        return _inst;
    }
    public void count() { count++; }
    public int getCount() { return count; }
}
public class Test {
    public static void main(String[] args) {
        Connection conn1 = Connection.get();
        conn1.count();
        Connection conn2 = Connection.get();
        conn2.count();
        Connection conn3 = Connection.get();
        conn3.count();
        conn1.count();
        System.out.print(conn1.getCount());
    }
}
```

**정답:** 4

**해설**

## 7번 (5점)

원본: `public/20260927_080118.jpg`

3개의 페이지를 수용할 수 있는 주기억장치가 있으며, 초기에는 모두 비어 있다고 가정한다. 다음의 순서로 페이지 참조가 발생할 때, LRU와 LFU 페이지 교체 알고리즘을 사용하면 각각 페이지 결함의 발생 횟수를 쓰시오.
답: ① LRU :    ② LFU :

### 페이지 참조 순서

| 알고리즘 | 페이지 참조 순서 |
| --- | --- |
| LRU | 1, 2, 3, 1, 2, 4, 5, 1 |
| LFU | 1, 2, 3, 1, 2, 4, 1, 2, 3, 4 |

**정답:**

```
① 6
② 6
```

**해설**

프레임은 3개, 처음은 비어 있다.
LRU 참조 1,2,3,1,2,4,5,1: 적중은 네 번째(1)와 다섯 번째(2)뿐이고 나머지 6번은 부재다.
LFU 참조 1,2,3,1,2,4,1,2,3,4: 빈도 최소 페이지를 교체하고 빈도가 같으면 먼저 들어온 페이지를 뺀다. 4 진입 시 빈도 1인 3을 제거하고, 3 재진입 시 빈도 1인 4를 제거한 뒤, 마지막 4에서 다시 3을 제거한다. 부재는 6번이다.

**확인 메모**

- 사진에서 LRU/LFU 참조 순서는 표로 제시되고, ① LRU / ② LFU는 답란이다. 참조 순서를 보기 번호처럼 적지 않았다.

```c
void inverse(char *str, int len) {

        str[i] = str[j];
        str[j] = ch;
    }
}

int main() {
    char str[100] = "ABCDEFGH";
    int len = strlen(str);
    inverse(str, len);
    for (int i = 1; i < len; i += 2) {
        printf("%c", str[i]);
    }
    return 0;
}
```

**해설**

초깃값 "ABCDEFGH"를 inverse하면 HGFEDCBA가 된다. i=1부터 2씩 증가하며 출력하므로 인덱스 1,3,5,7인 G,E,C,A가 나온다.

## 11번 (5점)

원본: `public/20260927_080143.jpg`

다음 Java로 구현된 프로그램의 실행 순서를 나열하시오. (단, 같은 번호는 중복해서 작성하지 마시오.)

```java
class Parent {
    int x, y;
    Parent(int x, int y) { // ①
        this.x = x;
        this.y = y;
    }
    int getX() { // ②
        return x*y;
    }
}
class Child extends Parent {
    int x;
    Child(int x) { // ③
        super(x+1, x);
        this.x = x;
    }
    int getX(int n) { // ④
        return super.getX() + n;
    }
}
public class Main {
    public static void main(String[] args) { // ⑤
        Parent parent = new Child(10); // ⑥
        System.out.println(parent.getX()); // ⑦
    }
}
```

**정답:** ⑤ → ⑥ → ③ → ① → ⑦ → ②

**해설**

실행은 main(⑤)에서 시작한다. ⑥ `new Child(10)`에서 자식 생성자(③)가 호출되고, `super(x+1, x)`로 부모 생성자(①)가 실행된다. 생성이 끝난 뒤에 ⑦ 출력문으로 넘어간다. println의 `parent.getX()`는 참조 타입이 Parent이고 `getX(int n)`은 오버로드라 ④는 호출되지 않으며, 인자 없는 ②가 실행된다. ⑦을 생성자보다 앞에 두면 안 된다.

**확인 메모**

- 사진의 원 숫자는 코드 왼쪽 여백에 있다. 전사본에는 같은 위치에 `// ①` 형태로만 표시했다.
- ① Parent 생성자, ② Parent.getX(), ③ Child 생성자, ④ Child.getX(int n), ⑤ main, ⑥ new Child(10), ⑦ println.
- `public class Main` 줄에는 원 숫자가 없다.

```c
#include <ctype.h>

int main() {
    char *p = "It is 8";
    char result[100];
    int i;
    for (i = 0; p[i] != '\0'; i++) {
        if (isupper(p[i]))
            result[i] = (p[i] - 'A' + 5) % 26 + 'A';
        else if (islower(p[i]))
            result[i] = (p[i] - 'a' + 10) % 26 + 'a';
        else if (isdigit(p[i]))
            result[i] = (p[i] - '0' + 3) % 10 + '0';
        else if (!(isupper(p[i]) || islower(p[i]) || isdigit(p[i])))
            result[i] = p[i];
    }
    result[i] = '\0';
    printf("변환된 문자열 : %s\n", result);
    return 0;
}
```

**정답:** 변환된 문자열 : Nd sc 1

**해설**

문자열 "It is 8"을 한 글자씩 변환한다. 대문자 I는 +5 → N, 소문자 t/i/s는 +10 후 26으로 순환 → d/s/c, 공백은 그대로, 숫자 8은 +3 → 1. printf 서식 그대로 `변환된 문자열 : Nd sc 1`이 한 줄로 출력된다.

**확인 메모**

- 사진의 대문자 분기 % 25는 알파벳 순환이 아니므로 소문자와 같이 % 26으로 고쳤다.
- 이 입력에서는 % 25와 % 26의 출력 문자열이 같다. gcc로 확인했다.

| --- | --- |
